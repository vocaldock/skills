# VocalDock skills

The VocalDock agent skill lets AI coding agents (Codex, Claude Code, Cursor and others) use
[VocalDock](https://vocaldock.com): vocal separation, stem splitting, noise removal, text to speech,
music generation, and finding past results.

The skill is served from vocaldock.com. Install it with:

```bash
npx skills add https://vocaldock.com
```

Then sign in once:

```bash
npx -y vocaldock@latest login
```

Tasks use the credits on your VocalDock account.

Found a problem? Open an issue here or email hi@vocaldock.com.
