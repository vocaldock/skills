# VocalDock skills

Agent skill that lets AI coding agents (Codex, Claude Code, Cursor and others) use [VocalDock](https://vocaldock.com):
vocal separation, stem splitting, noise removal, text to speech, music generation, and finding past results.

```bash
npx skills add vocaldock/skills
```

Then sign in once:

```bash
npx -y vocaldock@latest login
```

Tasks use the credits on your VocalDock account. Questions: hi@vocaldock.com
